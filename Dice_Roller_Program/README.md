# 🎲 Dice Roller

A simple **Dice Roller** web application built with **HTML, CSS, and JavaScript**.

This is one of my beginner JavaScript projects, created to practice DOM manipulation, events, loops, random numbers, and dynamically adding HTML elements.

## 📸 Preview

The user chooses how many dice to roll, then clicks **Roll**.
The application generates a random result for each dice and displays the corresponding image.

## ✨ Features

* 🎲 Roll multiple dice
* 🔢 Choose between 1 and 6 dice
* 🎯 Random dice results
* 🖼️ Displays the corresponding dice images
* ⚠️ Input validation for invalid numbers
* 🔄 Clears the previous results before each roll

## 🚀 How to Run

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_LINK
```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Enter the number of dice you want to roll.

5. Click **Roll** 🎲
