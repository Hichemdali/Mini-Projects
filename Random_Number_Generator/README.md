# Random Number Generator

A simple Random Number Generator built with **HTML**, **CSS**, and **JavaScript**. This project generates a random number within a specified range when the user clicks a button.

## Features

- Generate random numbers instantly
- Clean and responsive interface
- Built using vanilla JavaScript
- Beginner-friendly project

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## Project Structure

```
Random-Number-Generator/
│── index.html
│── style.css
│── script.js
└── README.md
```

## How It Works

1. Open the application in your browser.
2. Click the **Generate** button.
3. A random number is displayed on the screen.

## What I Learned

While building this project, I practiced:

- DOM manipulation

- Using the `Math` object
- `Math.random()`
- `Math.floor()`
- Updating HTML elements with JavaScript
- Separating HTML, CSS, and JavaScript files
