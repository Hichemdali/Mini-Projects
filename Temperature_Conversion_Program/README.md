# 🌡️ Temperature Converter

A simple **Temperature Converter** built with **HTML, CSS, and JavaScript**.

This project converts temperatures between **Celsius (°C)** and **Fahrenheit (°F)** using JavaScript and DOM manipulation.

## 🚀 Features

* 🌡️ Convert Celsius to Fahrenheit
* 🔥 Convert Fahrenheit to Celsius
* 🖱️ Simple button-based interaction
* ⚡ Instant conversion without reloading the page
* 🎨 Simple and clean user interface
* 📱 Basic responsive layout

## 🛠️ Technologies Used

* **HTML5** — Structure of the webpage
* **CSS3** — Styling and layout
* **JavaScript** — Conversion logic and DOM manipulation

## 📐 Conversion Formulas

### Celsius → Fahrenheit

```text
°F = (°C × 9/5) + 32
```

### Fahrenheit → Celsius

```text
°C = (°F − 32) × 5/9
```
